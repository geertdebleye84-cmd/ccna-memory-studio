# Contributing to CCNA Memory Studio

Contributions are welcome under the GNU General Public License v3.0.

Before opening a pull request:

1. Keep the core application usable without internet, AI providers or a logged-in browser.
2. Do not add Cisco/Pearson exam dumps, copied exam questions, lesson text or protected artwork.
3. Keep personal progress, PDFs, generated audio, credentials, browser data and local machine paths out of Git.
4. Preserve stable progress formats and existing data identifiers.
5. Run `npm run check` and `npm test` and describe the result.

For new course content, write original explanations and questions. Small,
focused pull requests are easier to review; explain the learner problem and
the resulting behavior.
