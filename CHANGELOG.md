# Changelog

## 3.0.0 — Initial public source release

- Offline-first Learn and Test workflows.
- CCNA1, CCNA2 and CCNA3 course libraries with isolated progress.
- Original flashcards, checkpoints, final practice and reverse-diagnosis items.
- Safe Cisco IOS, PowerShell and CMD CLI Practice Lab.
- Diagram Trainer and Tester with local PDF preview support.
- Optional local Ollama and visible browser AI bridge.
- Windows Electron packaging for NSIS and portable builds.

This is an independent learning tool. It is not an official Cisco or NetAcad
application and does not include copied Cisco/Pearson exam questions.
