# CCNA2 content plan

Status: ACTIVE — 2026-08-20

The CCNA2 learning layer follows the visible Cisco Networking Academy
**Switching, Routing, and Wireless Essentials** outline for modules 1–16.
Introductory `x.0` lessons are intentionally omitted at the user's request.

Content rules:

- Explain every substantive `x.1` and later section in original wording.
- Preserve the existing 505-card catalogue and its progress format.
- Use original diagrams; do not copy Cisco/Pearson artwork.
- Do not reproduce official assessment questions or answer banks.
- Supply original practice questions with answers and explanations.
- Include IOS command patterns, verification, troubleshooting, and labs.
- Cross-check protocol defaults and commands against Cisco documentation.
