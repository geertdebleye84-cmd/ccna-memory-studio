# Requirements

## Active

- REQ-001: Preserve distinct study and test modes.
- REQ-002: Study alternates question and answer; fixed bottom controls remain
  visible and include Next, speech, OK, and Attention behavior.
- REQ-003: English questions/answers support translation to other languages.
- REQ-004: Save/load sessions, notes per card, undoable progress, known and
  attention groups, chapter/bundle selection, and spaced repetition.
- REQ-005: Local Piper AI speech supports English and Dutch, continuous reading,
  configurable pauses and speed, and follows the visible text.
- REQ-006: Provide collapsible/dockable research, video, reference, notes,
  settings, speech, and memory-palace areas.
- REQ-007: Keep 505 catalog records and book/Jeremy mappings available.
- REQ-008: Add an optional course importer that can create a separate course
  from PDF/EPUB/DOCX/text, with AI-assisted reviewable card/test generation.
- REQ-009: Recover the LurnAI AI communication bridge for optional Ollama and
  visible logged-in webchat providers without importing licensing/security code.
- REQ-010: Core learning remains functional when AI is unavailable.
- REQ-011: Provide a side-effect-free CLI trainer for Cisco IOS topics aligned
  to NetAcad 1, 2, and 3, with optional PowerShell and Windows CMD profiles.
- REQ-012: CLI practice supports context-sensitive prompts, common unique IOS
  abbreviations, realistic error feedback, selectable topic sets, command
  history/help/completion, and a short-interval spaced-repetition action.
- REQ-013: Provide a complete browsable CCNA1 learning layer for all substantive
  NetAcad modules while omitting `x.0` introductions.
- REQ-014: Course layers use original explanations, diagrams, labs and practice
  questions, remain selectable without replacing one another, and keep progress
  isolated per course.
- REQ-015: CCNA course libraries provide separate per-module files and three
  learning modes: objective multiple choice, reverse diagnostic scenarios, and
  flashcards. Red-to-green knowledge lights must be based only on recorded
  correct objective answers, not on merely viewing content.
- REQ-016: Provide a separate diagram trainer/tester for the supplied CCNA
  diagrams, outside the normal study, test, course, and CLI modes. The trainer
  shows the local source diagrams with active-recall prompts; the tester hides
  the source, records objective answers separately, and shows evidence-based
  red-to-green mastery per diagram.
